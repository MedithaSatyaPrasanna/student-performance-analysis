# Student Performance Analysis

## About the Project
Student Performance Analysis is a beginner-friendly Python project that analyzes student academic performance using **NumPy** and visualizes the results using **Matplotlib**.

The project uses student data stored in a CSV file to calculate statistics, rank students, classify their performance, identify students who need academic attention, and display insights through charts.

## Features
- Load student data from a CSV file using NumPy.
- Calculate total and average marks.
- Display overall class statistics.
- Perform subject-wise analysis.
- Analyze student attendance and study hours.
- Rank students based on average marks.
- Classify students into performance categories:
  - Excellent
  - Good
  - Average
  - Needs Improvement
- Identify students who require academic attention.
- Perform percentile analysis.
- Visualize data using Matplotlib:
  - Subject-wise average marks (Bar Chart)
  - Student performance distribution (Pie Chart)
  - Student-wise average marks (Bar Chart)
  - Study hours vs average marks (Scatter Plot)
